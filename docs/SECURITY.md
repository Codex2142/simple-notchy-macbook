# Project Island — Security & Privacy

## Core Security Principles

1. **Local-First & Offline-Capable:** All core features operate locally without cloud dependencies or telemetry.
2. **No Plaintext Credentials:** Secrets and tokens are stored exclusively in macOS Keychain via `KeychainAdapter` (`Security.framework` with `kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly`).
3. **Clipboard Privacy Filtering:**
   - Rejects clipboard capture whenever macOS Secure Event Input (`IsSecureEventInputEnabled()`) is active.
   - Rejects items tagged with sensitive pasteboard markers (`org.nspasteboard.ConcealedType`, `org.nspasteboard.TransientType`, `org.nspasteboard.AutoGeneratedType`, `com.agilebits.onepassword`, `de.anea.keepassmac.password`).
4. **On-Demand Permissions:** `PermissionManager` checks permission state passively (`AXIsProcessTrusted()`) and only prompts the user when a feature requiring elevated access is explicitly invoked.
5. **Public APIs Only:** Uses documented AppKit, IOKit, Mach, Security, and DistributedNotificationCenter APIs without private framework dependencies.
